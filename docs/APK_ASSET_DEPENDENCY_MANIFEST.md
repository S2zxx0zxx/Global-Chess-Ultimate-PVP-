## Private manifest contract
file_manifest.csv: archive/member identity, bytes, SHA256, dimensions, integrity, ship decision.
unity_objects.csv: serialized file + decimal string PathID, class/type, bounds, SHA256. Preserve IDs as strings to avoid JS 64-bit precision loss.
dependency_edges.csv: source file/ID, field, file ID, target ID/file/type, external path, status, link kind. Nulls are separate; resolved means target record exists only. external_tables.csv: original external-file indexes and map status.
duplicate_groups.json: byte identity (not perceptual matching). asset_paths.csv: container links. sprite_manifest.csv: dimensions, pivot, border, PPU, texture/atlas/trim/packing, export hash/integrity. texture_manifest.csv: source format and dimensions, raw/PNG hashes.
chess_subset.csv, audio_manifest.csv, spine_manifest.csv, animation_manifest.csv, layout_manifest.csv: category-specific links. unresolved.csv and summary.json: counts and exceptions. README and Python tools describe reproducible inputs and validation.
