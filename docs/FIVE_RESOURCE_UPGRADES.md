## Geometry and integration
- Eight source-derived 2D and 3D palettes, original colors and border geometry dimensions. Existing four board skins preserved. Reversed border variants preserve standard chess square orientation.
- All six low-poly meshes bundled as compact CC0-derived volume data. Every source triangle surface was checked against exact voxel-cell boundary, and all four color variants were checked for identical geometry buffers. Greedy surface mesh preserves voxel silhouette and material palette; not byte-identical glTF. No external download needed for the low-poly fallback. Two selectable pairings cover all four source colors.
- Four premium original FBX themes coexist with prior five. Whole-set FBX loader chooses named piece nodes with nested accessories, validates twelve prototypes, normalizes scale and pivots, retains procedural fallback as emergency, and loads high-poly only on explicit selection. The source creator Georgez05 (https://georgez05.itch.io/chess-pack-high-and-low-poly) publicly stated users may use the pack however they want, credit appreciated. Source includes no formal license document. Keep attribution.
- GitHub connector cannot transport the large original binaries directly from the attachment runtime. Extract the separately provided Global_Chess_Premium_3D_Integration_Assets.zip into the repository root; no existing asset manifest is overwritten. Run npm run assets:verify:five. The original FBX data is unchanged and verified against SHA-256. Until the pack is installed, these four themes correctly fall back to bundled low-poly pieces. No claim that these themes ship in the remote preview yet.
- Premium models are on-demand online/local-build resources; no claim of offline cache availability for them. Actual browser/physical Android and high-poly memory validation remains open.
