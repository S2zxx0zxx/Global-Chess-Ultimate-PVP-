# Five-resource integration
Baseline ad1a708e17d8e15220d37d39988ba6cee8ed304f. Scope limited to 8 board variants, opponent selection, dedicated low-poly models, four additional FBX sets, and opening recognition. Existing five 3D families, rules, AI, clocks and server authority retained. Ludo excluded.

Opening data: 30 unique labels from supplied excerpt, corrected legal SAN/ECO using https://github.com/lichess-org/chess-openings (CC0). Some original position strings were impossible or mislabeled; no original application code redistributed. Selection is an authenticated transient WebSocket event, not a move or a stored state. No rated mode exposure.

Assets: Kytric Voxel Board Games CC0 (https://kytric.itch.io/board-game-assets). Premium source license not established; do not publish raw premium binaries until clearance. Device/browser, hosted two-client and CI gates remain required. This is a draft implementation, not a production certificate.
