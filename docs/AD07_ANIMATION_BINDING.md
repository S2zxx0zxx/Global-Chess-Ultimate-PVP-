## Evaluation
scripts/ad07_evaluator.mjs is dependency-free read-only evaluator. Preserve boundary initial value, exact-key values (including signed zero), per-segment cubic coefficients, constant channels and unweighted direct Hermite curves. No synthesized dense data, automatic loop wrapping, runtime callback execution, property writes, or controller blending. Event windows (previous,current] with explicit once-at-start option and stable equal-timestamp order. Unsupported formats rejected. Source evaluation 106/106, 1,964 channels, all 4,747 timed keys exact, 3,331 inter-key segments (300 constant-polynomial jumps above .001; maximum continuous endpoint difference .000044492326821909955, tolerance .001), 22 direct keyframes exact, 5,387 sample times / 151,585 scalar samples finite, 96/96 events preserved in split intervals. Four dedicated Node fixture tests passed (polynomial/constant/clamp/Hermite, hold and signed zero, event order, unsupported/malformed profiles). This validates mathematics against source keys and test vectors, NOT independent Unity runtime parity or callbacks.
