# P02 — AI worker foundation

Scope: all eight GCU-P02 tasks. P00/P01 baseline and 50-route UI retained. The supplied Engine.cs, AI.cs and Evaluation.cs were re-inspected for lifecycle, time and evaluation concepts. No proprietary code or lookup tables are included. P03 recursive search, iterative deepening and quiescence are not implemented here.

- T01: protocol v1 typed identity, position history, bounded request and result validators; one-ply legal PV and discriminated score. Input bounds: 1024 plies, FEN 160 chars, 1–2000ms, max 256 root nodes, depth exactly one.
- T02: one worker per job; single resolution, hard-stop at requested time + 120ms scheduling grace, termination on completion/error/cancel. App invalidates on moves, undo, restart, resume, pause, resign, route exit and match end; replay and hint jobs independently cancel. Existing synchronous heuristic runs inside worker for default legacy strategy. No main-thread recursive/heuristic search in gameplay, hints or replay.
- T03: legal history replay from original FEN, exact canonical final FEN comparison, rejects illegal, terminal continuation and malformed input. Preserves repetition/counters. Older FEN-only saves cannot invent missing history.
- T04–T06: independent centipawn material, relative-rank/centrality piece-square formulas, phase-aware king, geometric mobility, pawn isolation/doubling, shelter; components sum once, mirrored, deterministic seeded tie order. Terminal score separate. This is a shallow evaluator, not Elo-rated.
- T07: partial result at deadline/node cap with no claimed completed depth or score; existing heuristic inside worker on evaluator exception if budget remains; worker unavailable/error/invalid payload -> deterministic legal root fallback, no heavy synchronous search, no score/depth fabrication, no personal data in diagnostics. No move in terminal state.
- T08: internal VITE_AI_WORKER_FOUNDATION=true opts into foundation evaluator; default legacy strategy uses same worker transport. Existing UI labels remain basic, no new strength claims. Caller compares game identity/revision/history and legal move before applying; clocks checked before move. Hints and replay analysis use advisory jobs; no online room changes.
- Browser CI uses simulated 360/414 mobile viewports, fixed P01 corpus, 10 rounds each, actual worker protocol, cancellation/late state checks, hard-stop and React saved computer match path. Cold worker creation adds latency; report round-trip and worker time separately, evaluate main-thread observations vs P01. Physical device, offline cache and full G2 search/tactical improvement remain P03/P09 acceptance scope.
