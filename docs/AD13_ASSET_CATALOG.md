## Theme loader
All 365 chess aliases match exact source-path and hash provenance: 11 board themes, 12 piece families with 144 chess and 144 chess2d sprites and 12 shadows, 15 highlights, 16 coordinate sprites, 23 preview/strip assets. Board/piece choices independent; source chess family is a sprite family, not a 3D mesh. 47 Spine serialized sets and three candidate variants retained with original page dimensions, material IDs/keywords, scale and mix; candidate associations unverified.
src/adoption/ad13-theme-loader.mjs requires trusted external expected catalog SHA256 and explicit byte provider. Validates schema, decimal identity, kind/status, content-addressed path, positive length and image metadata; checks each loaded sprite length and SHA256. Rejects missing/unknown/review/blocked assets, path traversal, incomplete piece sets and unknown theme/mode. Returns complete transaction only, no partial theme; caller must keep current theme on failure. No default network endpoint, game state changes or renderer hook-up. No production release allowlist or public asset copy; quarantine still enforced.
